# access_return_rank 모델 개선 제안 (피쳐, ETL, 모델 관점)

> 대상 모델: `01_20_access_return_rank`
> 기준 분석: 2026-06-10 예측 결과 및 top-10 종목 기여도 분해 (`topk_2026-06-10_top10_해설.md`)

최근 2026-06-10 기준 예측 결과를 분석한 결과, 모델이 **데이터 결측 패턴을 업종 더미로 오인**하고 있으며, **역추세/저변동성 피쳐에 과도하게 의존**하여 실제 수익률(holdout spread)이 부진한 현상이 확인되었습니다. 이를 해결하기 위한 단계별 개선점을 제안합니다.

---

## 1. 피쳐 관점 (Feature Engineering)

### 1.1 업종 특화 재무 피쳐 도입
현재 금융주(은행, 증권, 보험 등)는 일반 제조업 중심의 재무비율(`roa`, `operating_margin`, `debt_to_equity`)이 체계적으로 결측되어 모델이 이를 `isna` 플래그로만 인식하고 있습니다.
- **개선**: 금융업종에 유의미한 지표를 `research/etl/features/fin_pit.py`에 추가.
    - **은행/지주**: `BIS 비율`, `NIM(순이자마진)`, `고정이하여신비율`
    - **증권**: `순자본비율(NCR)`, `위탁매매 수수료 비중`
    - **보험**: `RBC 비율` 또는 `K-ICS`, `경과손해율`
- **기대효과**: 금융주 내에서도 펀더멘털에 따른 변별력을 확보하고, 단순히 "금융주라서" 점수가 높아지는 편향 제거.

### 1.2 섹터/업종 중립화 피쳐 (Sector-Neutral Features)
현재 모델은 "최근 60일 하락" 종목을 선호하는데, 이것이 업종 전체의 하락인지 개별 종목의 특이 현상인지 구분하지 못합니다.
- **개선**: 가격 및 수급 피쳐에 대해 섹터 상대값 추가.
    - `px_ret_60d_rel_sector`: 섹터 지수 대비 초과 수익률
    - `flow_foreign_netbuy_z_sector`: 섹터 내 타 종목 대비 외국인 수급 강도
- **기대효과**: 특정 업종 전체가 하락할 때 모든 종목이 상위에 랭크되는 '쏠림 현상' 방지.

## 2. ETL 및 데이터 파이프라인 관점 (Data & ETL)

### 2.1 데이터 결측 처리 전략 고도화
현재 Ridge 모델은 L1 전처리에서 생성된 `*_isna` 플래그를 그대로 사용하며, 특정 업종에서 결측이 발생할 때 이를 강력한 신호로 학습합니다.
- **개선**: 
    - **업종별 중앙값 대체**: 결측치를 전체 평균이 아닌 동일 업종 내 중앙값으로 대체하여 `isna` 플래그의 영향력 감소.
    - **커버리지 확장**: `dart_financial_statement_raw` 및 `dart_xbrl_fact_raw`를 활용해 현재 `stock_metric_fact`에서 누락된 금융업종 항목 백필.
- **기대효과**: 모델이 데이터의 '부재'가 아닌 '내용'에 집중하도록 유도.

### 2.2 업종 매핑 데이터(PIT) 정교화
현재 프로젝트 내에 업종 매핑(`hs_sector_mapping` 등) 계획은 있으나, 학습 패널에 Point-in-Time으로 결합되어 있지 않습니다.
- **개선**: KRX 업종 분류 또는 GICS 수준의 PIT 업종 매핑을 `dim_universe_daily`에 결합하여 피쳐 생성 시 참조 가능케 함.

## 3. 모델 관점 (Modeling)

### 3.1 비선형 모델 및 트리 기반 모델 도입
현재 Ridge(선형) 모델은 결측 플래그와 피쳐 간의 복잡한 상호작용을 선형 결합으로만 처리합니다.
- **개선**: `LightGBM` 또는 `XGBoost` 도입 고려.
    - 트리 모델은 결측치(NaN)를 자체적으로 처리하는 능력이 있으며, 특정 피쳐 조합(예: 업종 AND 저변동성)의 비선형적 효과를 더 잘 포착함.
- **기대효과**: 단순히 결측 플래그 계수 합산으로 점수가 결정되는 선형 모델의 한계 극복.

### 3.2 손실 함수 및 타깃 재설계
현재 `y_rank_20d`는 횡단면 순위만 보존하며, 상위 종목 간의 '실제 수익률 격차'를 반영하지 못합니다.
- **개선**: 
    - **Weighted Ridge/Regression**: 수익률 변동성이 큰 시기나 종목에 가중치를 부여.
    - **Top-K Focused Loss**: 상위 10% 종목의 적중률(Hit Ratio) 또는 Spread를 직접 최적화하는 목적 함수 검토.
- **기대효과**: Rank IC는 높으나 Spread가 낮은(순위는 맞는데 돈은 안 되는) 현재의 괴리 현상 해결.

## 4. 요약 및 우선순위

1. **우선순위 상 (즉시 적용)**: 업종별 중앙값 대체 또는 금융업종 주요 지표(`fin_roa` 등) 커버리지 재점검.
2. **우선순위 중 (차기 마일스톤)**: 트리 기반 비선형 모델(LightGBM) 실험 및 업종 중립화 피쳐 추가.
3. **우선순위 하 (장기 과제)**: 업종 특화 KPI(운영 지표) 자동 추출 엔진 연결.
