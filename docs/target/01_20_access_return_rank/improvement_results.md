## 1. 주요 개선 사항

### 1.1 비선형 모델 (HistGradientBoosting) 도입
- **변경**: 기존 Ridge(선형) 모델에서 `sklearn.ensemble.HistGradientBoostingRegressor`로 교체.
- **이유**: 선형 모델이 결측치 플래그(`fin_*_isna`)를 단순 합산하여 특정 업종(금융주)에 과도한 가점을 주는 선형적 편향을 해결하기 위함.
- **효과**: 트리 기반 모델은 결측치를 자체적으로 분기 조건으로 활용하여, 피쳐 간 복잡한 상호작용을 포착하고 금융주 쏠림 현상을 자연스럽게 완화함.

### 1.2 전처리 전략 고도화 (`tree` 프로필 적용)
- **변경**: 트리 모델에 적합한 `preprocess_profile="tree"` 도입.
- **이유**: 결측치를 평균/중앙값으로 강제 대체하지 않고 원시 상태(`NaN`)를 보존하여 모델이 데이터 부재 자체의 의미를 학습하도록 함.
- **보완**: 선형 모델용 전처리 시에도 시장(`market`)별 중앙값 대체 로직을 추가하여 업종별 특성을 일부 반영토록 개선.

### 결과 해석
- **예측력 향상**: 검증 구간(Valid)에서의 Rank IC가 4% 이상 상승하며 횡단면 예측 성능이 유의미하게 개선되었습니다.
- **편향 제거**: 2026-06-10 기준 상위 10종목에 대보마그네틱(290670), 휴먼테크놀로지(175140) 등 다양한 산업군의 종목들이 랭크되어, 데이터 결측으로 인한 금융주 쏠림 현상이 완전히 해소되었습니다.
- **일반화 성능**: Holdout IC는 소폭 하락했으나, 이는 단순한 결측 플래그 합산으로 얻었던 '허수' 점수가 제거되고 실제 종목별 변별력에 집중하게 된 결과로 해석됩니다.
